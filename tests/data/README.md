# Test fixtures

## seg_image_ct_binary.dcm

A small binary DICOM-SEG (CT segmentation, 3 frames, 16x16, anisotropic
spacing) used to validate segauge's DICOM-SEG loader against a real-world file.

Vendored from the [highdicom](https://github.com/ImagingDataCommons/highdicom)
project's test data (`data/test_files/seg_image_ct_binary.dcm`), distributed
under the MIT License (Copyright 2020 MGH Computational Pathology). Included
here under those terms.
